# internconnect
Internship platform with Admin, Student, and Company portals built using React, Node.js, and MongoDB.
## Current Features

- Student registration and login
- Company registration and login
- Admin portal
- Internship management
- Student internship applications
- Company application management
- Backend API integration
- MongoDB database integration

## Project Status
The InterConnect platform provides separate portals for students,
companies, and administrators to manage internships and applications.
